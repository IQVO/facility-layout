# Security Policy

## Supported Versions

Security fixes are applied to the current `develop` branch. Please use the
latest commit from that branch when verifying a report.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities, credentials, or proof-of-concept
payloads in a public issue. Instead, open a private vulnerability report via
GitHub's built-in disclosure workflow:

https://github.com/IQVO/facility-layout/security/advisories/new

Include a description of the impact, affected commit/version, reproducible
steps, and any suggested mitigation.

The maintainer will acknowledge reports, assess their impact, coordinate a
fix, and publish a disclosure after a remediation is available.
